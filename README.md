# Взаимодействие
- ``add <id> <name> <email>`` - добавить пользователя с указанными параметрами (ID **должны** быть уникальны)
- ``add <file-path>`` - импорт пользователей из текстового файла
- ``print`` - вывод всех пользователей
- ``filter <text>`` - фильтрация и вывод пользователей, которые имеют \<text> либо в name, либо в email
- ``map <name|email>`` - вывод определенного поля всех пользователей
- ``sort <id|name|email> [asc|desc] [quick|bubble]`` - сортировка пользователей по выбранному полю, опционально направление сортировки и алгоритм
- ``Exit`` - выход из программы
## Формат файла с пользователями
Каждая строка определяет одного пользователя, формат: ``id name email``. **Все поля должны** присутствовать, опциональных полей **нет**, ID **должны** быть уникальны
